# p2ptd-inventory

Скрипты для наполнения InvenTree (https://p2ptd-inventory.online), Telegram-бот для добавления оборудования по фото и сборка Android-приложения.

**Как всё запустить по шагам: [docs/INSTALL.md](docs/INSTALL.md).** Устройство бота: [docs/BOT.md](docs/BOT.md), план работ: [docs/PLAN.md](docs/PLAN.md).

## Подготовка (один раз)

1. Установите Python 3 и PyYAML: `pip install -r requirements.txt`
2. Получите API-токен в InvenTree: меню пользователя → Настройки аккаунта → API-токены (Access tokens) → создать.
3. Скопируйте `.env.example` в `.env` в этой же папке и впишите токен:
   ```
   INVENTREE_URL=https://p2ptd-inventory.online
   INVENTREE_TOKEN=inv-...
   ```
   `.env` лежит только у вас на компьютере, в git он не попадает (указан в `.gitignore`). Не коммитьте токен и не отправляйте его в чат.

## Порядок запуска

У каждого скрипта есть `--dry-run`: он показывает, что будет сделано, и ничего не отправляет на сервер.

```
python create_locations.py      # заведения и места хранения
python create_categories.py     # дерево категорий
python import_stock.py --dry-run
python import_stock.py          # оборудование из data/riders/*.yaml
python renumber_serials.py      # один раз: номера P2PTD-00001 → P2PTD0001 (есть --dry-run)
```

Все скрипты можно запускать повторно: то, что уже есть, пропускается.

## Данные из райдеров

`data/riders/<заведение>.yaml` — оборудование, разобранное из райдеров (исходники лежат в `data/riders/source/`). Перед загрузкой проверьте и поправьте эти файлы: категорию, место, количество. Формат описан в начале `rovesnik.yaml`.

Позиции загружаются со статусом «Требует внимания». В примечании записан источник и, если нужно, что проверить. При обходе:

1. Сверьте позицию с тем, что стоит на месте.
2. Для техники с серийниками: Действия → Serialize stock, введите серийники через запятую. Из одной позиции «4 шт.» получится 4 позиции, по одной на серийник.
3. Поставьте статус OK.
